# Dataset de evaluación

Ponga aquí un JSON por texto (formato en [`evals/README.md`](../README.md#dataset-evalsdatasets)): el original, su
adaptación hecha por profesionales, la fuente y la licencia. **Solo textos públicos o sin datos personales.**

`ejemplos/` tiene dos textos inventados para la simulación (`--dry-run`) y los tests: no se usan en una evaluación real.
