# Ejemplos de exportación (US-14)

Un mismo texto de ejemplo (datos inventados) exportado en los cuatro formatos con la maquetación por defecto
(`ExportOptions`): letra de 14 pt, interlineado 1,5, alineación a la izquierda y una frase por línea.

| Fichero | Formato | Para qué |
|---|---|---|
| [`ayudas-para-pagar-el-alquiler.docx`](ayudas-para-pagar-el-alquiler.docx) | DOCX | Seguir editando en Word o LibreOffice (formato principal) |
| [`ayudas-para-pagar-el-alquiler.pdf`](ayudas-para-pagar-el-alquiler.pdf) | PDF | Enviar a validación o publicar tal cual. Lleva Atkinson Hyperlegible incrustada |
| [`ayudas-para-pagar-el-alquiler.md`](ayudas-para-pagar-el-alquiler.md) | Markdown | Publicar en webs, wikis o repositorios. Las direcciones van como código, nunca como enlace |
| [`ayudas-para-pagar-el-alquiler.txt`](ayudas-para-pagar-el-alquiler.txt) | Texto | Copiar en cualquier sitio o integrar con otros sistemas |

Todos llevan el aviso «Borrador · pendiente de validación» con la fecha: en el pie de cada página en DOCX y PDF, y al
final en Markdown y texto.
